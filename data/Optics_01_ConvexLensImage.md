# [심화 물리 강의록] 파동과 광학: 볼록렌즈에 의한 상의 형성 및 렌즈 공식

---

## 1. 볼록렌즈의 광선 작도법 (Ray Tracing) 및 주요 물리량 정의 [00:05]

볼록렌즈(Convex Lens)는 빛을 모으는 수렴 렌즈(Converging Lens)로, 물체에서 나온 빛이 렌즈를 통과하며 굴절되는 경로를 기하학적으로 추적함으로써 상의 위치와 크기를 결정할 수 있습니다.

```
                   [ 광선 작도 기본 개념도 ]

            광축 (Optical Axis)
   -----------O-----------+-----------F-----------I-----------
             /|           |          /          / |
            / |           |         /          /  | (실상)
   (물체)  /  |           |        /          /   v
          /   |           |       /          /
   ------/----+-----------+------/----------+-----------------
              <----- p ---><-- f ->
              <-------------- q ------------>
```

### 1.1 주요 광선 작도법 2가지 [00:58]
물체의 한 점(주로 최상단)에서 출발하는 대표적인 두 광선의 경로를 그립니다.
1. **평행 광선**: 광축(Optical Axis)에 평행하게 입사한 광선은 렌즈에서 굴절된 후, 반대편 **실초점($F$, Real Focus)**을 통과합니다.
2. **중심 광선**: 렌즈의 기하학적 중심(Optical Center)을 지나는 광선은 굴절 없이 그대로 **직진**합니다.

이 두 광선(또는 광선의 연장선)이 만나는 지점에 물체 최상단의 **상(Image)**이 형성됩니다.

---

### 1.2 렌즈 관련 주요 물리량의 정의 [02:15]
* **초점거리 ($f$, Focal Length)**: 렌즈 중심으로부터 초점($F$)까지의 거리.
* **물체거리 ($p$, Object Distance)**: 렌즈 중심으로부터 실제 물체까지의 거리.
* **상거리 ($q$, Image Distance)**: 렌즈 중심으로부터 형성된 상까지의 거리.

---

## 2. 렌즈 공식 (Thin Lens Equation)과 부호 규약 [08:15]

닮음비 등 기하학적 관계로부터 얇은 렌즈 공식(Thin Lens Formula)이 도출됩니다.

$$\frac{1}{p} + \frac{1}{q} = \frac{1}{f}$$

---

### 2.1 렌즈 공식 부호 규약 (Sign Convention) [02:55]
광학 문제를 해결할 때 가장 중요한 것은 각 변수의 **부호 규약**을 엄밀하게 적용하는 것입니다.

| 물리량 | 부호 | 물리적 의미 |
| :--- | :---: | :--- |
| **초점거리 ($f$)** | $f > 0$ | **수렴 렌즈 (볼록렌즈)**, 실초점 |
| | $f < 0$ | **발산 렌즈 (오목렌즈)**, 허초점 |
| **물체거리 ($p$)** | $p > 0$ | **실물체 (Real Object)** (렌즈 전방에 위치) |
| | $p < 0$ | **허물체 (Virtual Object)** |
| **상거리 ($q$)** | $q > 0$ | **실상 (Real Image)**: 렌즈 후방(빛이 실제로 모이는 쪽)에 형성 |
| | $q < 0$ | **허상 (Virtual Image)**: 렌즈 전방(물체가 있는 쪽)에 형성 |

> **[교사 팁 / 오개념 주의]** [03:05]  
> 학생들이 광학 단원에서 가장 흔히 범하는 실수는 거리 개념을 단순 '길이(양수)'로만 생각하는 것입니다. 렌즈 공식에서의 $f, p, q$는 단순한 길이가 아니라 **방향성과 상의 성격(실상/허상, 수렴/발산)을 내포한 부호가 있는 유효 수치**임을 반드시 명심해야 합니다.

## 3. 물체 위치에 따른 상의 변화 분석 (시뮬레이션) [09:54]

물체거리 $p$와 초점거리 $f$의 상대적 관계에 따라 상의 위치, 크기, 정립/도립 여부가 달라집니다.

```
                             [ 물체 위치별 상의 성격 ]

 (정립 확대 허상)              (상 형성 불가)         (도립 확대 실상)     (도립 축소 실상)
      허상 영역                     |                     실상 영역
 <----------------->                |      <------------------------------------->
 -------------------F---------------F-------2F------------------------------------ 광축
       p < f              p = f        f < p < 2f          p > 2f
```

### 3.1 위치별 상의 성격 요약
1. **$p > 2f$ 범위** [11:00]:
   * 상의 위치: $f < q < 2f$
   * 상의 특징: **도립 축소 실상** (Inverted, Reduced, Real Image)
2. **$p = 2f$ 인 경우** [11:33]:
   * 상의 위치: $q = 2f$
   * 상의 특징: **도립 등가 실상** (Inverted, Equal-size, Real Image)
3. **$f < p < 2f$ 범위** [11:58]:
   * 상의 위치: $q > 2f$
   * 상의 특징: **도립 확대 실상** (Inverted, Enlarged, Real Image)
4. **$p = f$ 인 경우** [12:03]:
   * 굴절된 광선들이 서로 평행을 이루어 만나지 않습니다.
   * 상의 특징: **상이 형성되지 않음** ($q \to \infty$)
5. **$p < f$ 범위 (초점 안쪽)** [12:20]:
   * 굴절 광선이 발산하므로, 광선의 **역방향 연장선**이 물체 쪽에 교점을 형성합니다.
   * 상의 위치: $q < 0$ (렌즈 전방, 물체와 같은 쪽)
   * 상의 특징: **정립 확대 허상** (Upright, Enlarged, Virtual Image) $\to$ *돋보기의 원리*

## 4. 횡배율 (Lateral Magnification)과 상의 특성 [18:10]

**배율 ($m$, Magnification)**은 물체 높이 대비 상의 높이 비율을 의미하며, 물체거리 $p$와 상거리 $q$로 다음과 같이 정의됩니다.

$$m = -\frac{q}{p}$$

---

### 4.1 배율 $m$의 부호와 크기가 갖는 물리적 의미 [21:00]
* **배율의 크기 ($|m|$)**:
  * $|m| > 1$: 상이 물체보다 크다 (**확대상**)
  * $|m| = 1$: 상과 물체의 크기가 같다 (**등가상**)
  * $|m| < 1$: 상이 물체보다 작다 (**축수상**)
* **배율의 부호**:
  * $m > 0$: **정립상 (Upright Image)** $\implies$ 허상 ($q < 0$)일 때 성립 [21:40]
  * $m < 0$: **도립상 (Inverted Image)** $\implies$ 실상 ($q > 0$)일 때 성립 [22:00]

## 5. 실전 응용 예제 풀이 [13:55]

### [문제] [13:56]
> 초점거리 $f = 10\text{ cm}$인 볼록렌즈 앞 $5\text{ cm}$ 되는 위치에 물체를 놓았다.
> 1. 상의 위치 $q$를 구하고, 상의 성격을 판별하시오.
> 2. 이 때의 배율 $m$을 구하시오.

---

### [해설 및 풀이] [15:00]

#### Step 1: 주어진 물리량에 부호 규약 적용
* 볼록렌즈이므로 초점거리 $f = +10\text{ cm}$
* 실물체이므로 물체거리 $p = +5\text{ cm}$

#### Step 2: 렌즈 공식을 이용한 $q$ 계산 [15:18]
$$\frac{1}{p} + \frac{1}{q} = \frac{1}{f}$$

$$\frac{1}{5} + \frac{1}{q} = \frac{1}{10}$$

$$\frac{1}{q} = \frac{1}{10} - \frac{1}{5} = -\frac{1}{10}$$

$$\therefore q = -10\text{ cm}$$

* **결과 해석** [15:35]:
  * $q = -10\text{ cm}$에서 마이너스($-$) 부호는 **허상(Virtual Image)**을 의미합니다.
  * 상은 **렌즈 전방(물체 쪽) $10\text{ cm}$ 위치**에 형성됩니다.

---

#### Step 3: 횡배율 $m$ 계산 및 상의 특성 최종 정리 [20:40]
$$m = -\frac{q}{p} = -\frac{-10}{5} = +2$$

* **결과 해석** [21:00]:
  * $m = +2$에서 플러스($+$) 부호는 상이 뒤집히지 않은 **정립상(Upright Image)**임을 나타냅니다.
  * 크기는 물체보다 **2배 확대**된 상입니다.
* **최종 답**: **렌즈 물체 쪽 $10\text{ cm}$ 위치에 2배 확대된 정립 허상이 형성된다.** [21:15]

---

### Step 4: 광선 작도를 통한 검증 [16:20]

```
                 [ 예제 문제 광선 작도 검증 ]

            (상: 정립 확대 허상)
                 |         | (물체)
                 |         |
     -----------*I*--------*O*--------O---------F---------- 광축
               / |        /|          |        /
              /  |       / |          |       /
             /   |      /  |          |      /
     -------/----+-----/---+----------+-----/--------------
            <---- 10cm ---->
            <-- 물체쪽 허상 ->
```

1. 물체($p = 5\text{ cm}$)에서 광축에 평행하게 나아간 빛은 굴절 후 우측 초점($f = 10\text{ cm}$)을 지납니다.
2. 물체에서 렌즈 중심을 지나는 빛은 굴절 없이 직진합니다.
3. 렌즈 우측으로 나아가는 두 빛은 서로 발산하므로 우측에서는 만날 수 없습니다.
4. 두 빛의 **좌측 연장선**을 그리면 렌즈 좌측 $10\text{ cm}$ 지점에서 교점이 형성되며, 물체보다 2배 큰 **정립 허상**이 그려집니다.

## 6. 핵심 개념 및 공식 요약 노트

$$\text{얇은 렌즈 공식: } \frac{1}{p} + \frac{1}{q} = \frac{1}{f} \quad \Big| \quad \text{횡배율 공식: } m = -\frac{q}{p}$$

* **실상 ($q > 0$)** $\iff$ **도립상 ($m < 0$)**: 렌즈 반대편(우측)에 맺히며 스크린에 상을 투영할 수 있음.
* **허상 ($q < 0$)** $\iff$ **정립상 ($m > 0$)**: 렌즈 같은 편(좌측)에 맺히며 스크린에 맺히지 않고 눈으로 직접 관찰해야 함.
