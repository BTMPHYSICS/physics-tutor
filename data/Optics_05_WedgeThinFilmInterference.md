# [심화 물리 강의록] 쐐기형 얇은 막에 의한 빛의 간섭 (Thin-Film Interference on a Wedge)

---

## 1. 물리적 상황 및 기본 조건 [00:00]

```
             \  | (입사광 λ)
              \ v
               +-----------------------+ 굴절률 n1 = 1 (공기)
              /                         \
             / θ (쐐기각 θ << 1)          \ 굴절률 n (유리/얇은 막)
------------+-----------------------------+-----------------
            | d(x) (두께)                 |
------------+-----------------------------+-----------------
                                            굴절률 n2 = 1 (공기)
```

- **실험 장치 구성**:
  - 매질 1 (상부): 공기 ($n_1 = 1$)
  - 매질 2 (쐐기형 막): 굴절률 $n$인 경사각 $\theta$의 얇은 유리 막
  - 매질 3 (하부): 공기 ($n_2 = 1$)
- **기본 가정**:
  - 쐐기각 $\theta$가 매우 작다 ($\theta \ll 1\text{ rad}$).
  - 단색광(결맞은 빛, 파장 $\lambda$)이 막 표면에 거의 수직으로 단면 전체에 균일하게 입사한다.

---

## 2. 광경로차 및 반사 시 위상 변화 분석 [01:49]

### (1) 광경로차 ($\Delta L$) 유도
쐐기 막의 임의의 위치 $x$에서 막의 두께를 $d$라 할 때, 윗면에서 바로 반사하는 광선(광선 1)과 윗면을 통과하여 아랫면에서 반사된 후 다시 나오는 광선(광선 2) 사이의 **왕복 거리**는 $2d$입니다.
따라서 매질의 굴절률 $n$을 고려한 **광경로차(Optical Path Difference, OPD)**는 다음과 같습니다.

$$\Delta L = 2nd$$

---

### (2) 반사 시 위상 변화 (Fixed-end vs Free-end Reflection) [02:55]
1. **상부 경계면 (공기 $n_1=1$ $\rightarrow$ 막 $n$)**:
   - 소한 매질에서 밀한 매질로의 반사이므로 **고정단 반사**가 발생합니다.
   - **위상 변화**: $\pi$ rad (파장 기준 $\frac{\lambda}{2}$ 차이 발생)
2. **하부 경계면 (막 $n$ $\rightarrow$ 공기 $n_2=1$)**:
   - 밀한 매질에서 소한 매질로의 반사이므로 **자유단 반사**가 발생합니다.
   - **위상 변화**: $0$ rad (위상 변화 없음)

> **[교사 팁 / 오개념 주의]**  
> 두 반사 광선 중 **단 한 곳(상부 경계면)에서만 위상 뒤집힘($\pi$ 위상 변화)**이 일어납니다. 따라서 일반적인 보강/상쇄 간섭 조건의 파장 조건이 반대로 뒤바뀝니다!

---

## 3. 보강 및 상쇄 간섭 조건 유도 [02:39]

한쪽 경계면에서만 위상이 $\pi$ 만큼 변하므로, 간섭 조건은 다음과 같이 정립됩니다.

### (1) 상쇄 간섭 조건 (어두운 무늬, Dark Fringe)
광경로차가 반파장의 **짝수 배**일 때 반사광은 위상차 $\pi$로 인해 상쇄됩니다.

$$\Delta L = 2nd = \frac{\lambda}{2}(2m) = m\lambda \quad (m = 0, 1, 2, \dots)$$

- **쐐기 꼭짓점 ($d = 0$, $m = 0$) 분석 [03:58]**:
  - 꼭짓점에서는 두께 $d=0$이므로 광경로차 $\Delta L = 0$입니다.
  - 하지만 상부 반사 시 위상 뒤집힘 때문에 **완전한 상쇄 간섭**이 일어나며, 꼭짓점 끝단은 **검게(어둡게)** 보입니다.

---

### (2) 보강 간섭 조건 (밝은 무늬, Bright Fringe) [03:08]
광경로차가 반파장의 **홀수 배**일 때 반사광은 보강됩니다.

$$\Delta L = 2nd = \frac{\lambda}{2}(2m + 1) \quad (m = 0, 1, 2, \dots)$$

각 밝은 무늬 위치에서의 막 두께 $d_m$:
- 첫 번째 밝은 무늬 ($m = 0$): $2nd_0 = \frac{\lambda}{2} \implies d_0 = \frac{\lambda}{4n}$
- 두 번째 밝은 무늬 ($m = 1$): $2nd_1 = \frac{3\lambda}{2} \implies d_1 = \frac{3\lambda}{4n}$
- 세 번째 밝은 무늬 ($m = 2$): $2nd_2 = \frac{5\lambda}{2} \implies d_2 = \frac{5\lambda}{4n}$

---

## 4. 무늬 간격 ($\Delta x$) 정량적 유도 [08:36]

```
Top View (위에서 바라본 무늬)
+---+-------+-------+-------+
|   |   |   |   |   |   |   |  <- 평행한 이웃한 밝은 무늬들
+---+-------+-------+-------+
    |<--Δx->|
   d0       d1
```

이웃한 두 밝은 무늬 사이의 수평 거리를 $\Delta x$라 하고, 각 위치에서의 막 두께를 $d_0$, $d_1$이라 합니다.

### (1) 기하학적 관계식
쐐기각 $\theta$에 대하여 thickness차이 $\Delta d = d_1 - d_0$는 다음과 같습니다.

$$\tan\theta = \frac{d_1 - d_0}{\Delta x} \implies d_1 - d_0 = \Delta x \tan\theta$$

---

### (2) 물리적 두께 차이 계산
이웃한 두 보강 간섭 지점의 두께 차이 $\Delta d$:

$$d_1 - d_0 = \frac{3\lambda}{4n} - \frac{\lambda}{4n} = \frac{\lambda}{2n}$$

---

### (3) 무늬 간격 $\Delta x$ 최종 유도 [10:01]
기하학적 관계식과 물리적 두께 차이를 연립합니다.

$$\Delta x \tan\theta = \frac{\lambda}{2n}$$

$$\Delta x = \frac{\lambda}{2n \tan\theta}$$

각도 $\theta$가 매우 작을 때($\theta \ll 1$), $\tan\theta \approx \theta \text{ (rad)}$ 근사를 적용하면:

$$\Delta x \approx \frac{\lambda}{2n\theta}$$

---

## 5. 심화 분석 및 실험적 응용 [10:44]

### (1) 미지의 물리량 측정 응용
유도한 식 $\Delta x = \frac{\lambda}{2n\tan\theta}$를 이용하면, 현미경으로 무늬 간격 $\Delta x$를 측정한 뒤 다음 미지수를 정밀 계산할 수 있습니다.
1. **광원의 파장 ($\lambda$) 측정**: $\lambda = 2n \Delta x \tan\theta$
2. **막의 굴절률 ($n$) 측정**: $n = \frac{\lambda}{2 \Delta x \tan\theta}$
3. **쐐기각 ($\theta$) 측정**: $\theta \approx \tan\theta = \frac{\lambda}{2n \Delta x}$

---

### (2) 평평한 막 vs 쐐기형 막의 간섭 무늬 비교 [12:10]

| 구분 | 두께 $d$의 특징 | 단색광 입사 시 간섭 무늬 형태 |
| :--- | :--- | :--- |
| **평면 얇은 막 (Flat Film)** | 전체 영역에서 두께 $d$ 일정 | 전체 면이 균일하게 **밝거나 어떰** |
| **쐐기형 얇은 막 (Wedge Film)** | 위치 $x$에 따라 두께 $d(x)$ 선형 증가 | 등간격의 **밝고 어두운 평행 직선 무늬** |
| **비누막/곡면 막 (Curved Film)** | 중력/곡률에 의해 두께 비선형 변화 | 간격이 일정하지 않은 **곡선 무늬 (무지개 무늬)** |

> **[교사 팁 / 시뮬레이션 직관] [13:05]**  
> 중력에 의해 아래로 갈수록 두꺼워지는 수직 비누막에 백색광을 비추면 파장별로 보강 간섭 조건이 달라져 상단에서 하단으로 갈수록 화려한 가로 무지개 띠가 형성됩니다. 단색광을 비추면 가로선 형태의 밝고 어두운 간섭 띠만 관찰됩니다.
