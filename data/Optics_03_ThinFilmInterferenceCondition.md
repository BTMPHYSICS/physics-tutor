# [심화 물리 강의록] 얇은 막의 간섭 조건 (Thin-Film Interference)

---

## 1. 기하학적 경로차 및 광학 경로차 유도

두께가 $d$이고 굴절률이 $n$인 얇은 막 표면으로 빛이 입사할 때, 막의 상단 표면에서 반사되는 빛(광선 1)과 막 내부로 굴절·침투하여 하단 표면에서 반사된 후 나오는 빛(광선 2) 사이의 경로차를 기하학적으로 유도합니다.

```
            입사광선 1, 2
               \   \
   굴절률 n_1   \   \
  ---------------\---\------------------- (상단 표면)
                  \   \  r
     굴절률 n      \ A \------- C
                    \   /
                     \ /
                      B                     (하단 표면)
  ---------------------------------------
                      |
                      | d
                      |
                     C'
```

### [01:38] 기하학적 경로차 유도 과정
1. 입사한 두 광선은 파면 수직선에 의해 동일한 위상면을 형성합니다.
2. 광선 1이 상단 표면의 $C$점에 도달하는 동안, 광선 2는 막 내부에서 $A$점까지 진행합니다.
3. 기하학적 대칭성을 이용하기 위해 하단 표면 $B$점 아래로 거울상(Image point) $C'$를 잡으면, $B$에서 $C$까지의 거리는 $B$에서 $C'$까지의 거리와 같습니다 ($\overline{BC} = \overline{BC'}$).
4. 따라서 두 광선이 막 내부에서 생성하는 기하학적 경로차 $\Delta L$은 다음과 같이 단순화됩니다.

$$\Delta L = \overline{AB} + \overline{BC} = \overline{AC'} = 2d \cos r$$

*   $d$: 막의 두께
*   $r$: 막 내부에서의 굴절각 (Refraction Angle)

---

### [04:25] 광학 경로차 (Optical Path Length Difference, OPLD)
빛이 매질(굴절률 $n$) 내를 진행할 때의 파장은 진공 중 파장 $\lambda$에 비해 $\lambda_n = \frac{\lambda}{n}$으로 줄어듭니다. 따라서 동일한 위상 변화를 진공 기준 거리로 환산한 **광학 경로차**는 기하학적 경로차에 굴절률 $n$을 곱해주어야 합니다.

$$\text{광학 경로차} = n \cdot \Delta L = 2nd \cos r$$

이를 파장 $\lambda$ 기준으로 나타내면 다음과 같습니다.

$$2d \cos r = \frac{\lambda}{2n} \cdot (\text{위상 인자})$$

## 2. 반사에 따른 위상 변화 (고정단 반사 vs 자유단 반사)

[07:30] 빛이 서로 다른 매질의 경계면에서 반사될 때, 굴절률의 대소 관계에 따라 반사파의 위상 변화가 발생합니다.

```
[고정단 반사]  n_1 < n_2 인 경계면 반사  -->  위상 변화 180° (π 라디안) [위상 뒤집힘]
[자유단 반사]  n_1 > n_2 인 경계면 반사  -->  위상 변화 0°               [위상 유지]
```

### [08:44] 고정단 반사 (Fixed-End Reflection)
*   **조건**: 소한 매질에서 밀한 매질로 입사할 때 ($n_1 < n_2$)
*   **특징**: 반사되는 순간 위상이 $\pi$ ($180^\circ$) 만큼 뒤집힙니다. (마루 $\leftrightarrow$ 골 반전)
*   **효과**: 반파장($\frac{\lambda}{2}$) 만큼의 광학 경로차가 추가로 발생한 것과 물리적으로 동일한 효과를 줍니다.

### [10:10] 자유단 반사 (Free-End Reflection)
*   **조건**: 밀한 매질에서 소한 매질로 입사할 때 ($n_1 > n_2$)
*   **특징**: 위상 변화가 전혀 없습니다 ($0$). 입사파의 위상 상태(마루/골)를 그대로 유지하며 반사됩니다.

## 3. 얇은 막의 간섭 조건 정리

[06:12] 고정단 반사가 일어나는 횟수에 따라 보강 간섭과 상쇄 간섭의 수식 조건이 역전됩니다.

### Case 1: 두 반사광 중 **고정단 반사가 1회** 발생하는 경우
상단 반사와 하단 반사 중 한 곳에서만 위상 뒤집힘($\pi$)이 발생하면, 기본 기하학적 경로차 조건에 대해 보강/상쇄 조건이 반대로 바뀌게 됩니다.

*   **상쇄 간섭 (Destructive Interference)**: 경로차가 반파장의 짝수 배일 때 (위상이 $\pi$ 뒤집혀 상쇄)
    $$2nd \cos r = m\lambda \quad \Longleftrightarrow \quad 2d \cos r = \frac{\lambda}{2n} (2m) \quad (m = 0, 1, 2, \dots)$$

*   **보강 간섭 (Constructive Interference)**: 경로차가 반파장의 홀수 배일 때
    $$2nd \cos r = \left(m + \frac{1}{2}\right)\lambda \quad \Longleftrightarrow \quad 2d \cos r = \frac{\lambda}{2n} (2m + 1) \quad (m = 0, 1, 2, \dots)$$

---

### Case 2: **고정단 반사가 0회 또는 2회** 발생하는 경우
두 반사광 모두 자유단 반사이거나, 둘 다 고정단 반사여서 위상 변화가 동등할 때(상쇄됨)는 일반적인 파동의 간섭 조건을 그대로 따릅니다.

*   **보강 간섭 (Constructive Interference)**:
    $$2nd \cos r = m\lambda \quad (m = 0, 1, 2, \dots)$$

*   **상쇄 간섭 (Destructive Interference)**:
    $$2nd \cos r = \left(m + \frac{1}{2}\right)\lambda \quad (m = 0, 1, 2, \dots)$$

> ### 💡 [교사 팁 / 오개념 주의]
>
> 1. **핵심 직관 (발상법)**:
>    * 막의 두께 $d$ 및 굴절률 $n$을 고려할 때, 항상 **"상단 반사파와 하단 반사파 각각의 위상 변화 여부"**를 제일 먼저 체크해야 합니다.
>    * $n_{\text{공기}} < n_{\text{막}} > n_{\text{기판}}$ 구조인지, $n_{\text{공기}} < n_{\text{막}} < n_{\text{기판}}$ 구조인지에 따라 간섭 조건식의 보강/상쇄 위치가 결정됩니다.
>
> 2. **자주 범하는 오개념**:
>    * "짝수 배($2m$)는 무조건 보강 간섭이다"라고 단정 짓는 오류를 범하기 쉽습니다. 고정단 반사가 1회 개입하면 **짝수 배 조건이 상쇄 간섭**이 됩니다.
>    * $2nd \cos r$ 식에서 $n$은 막 외부의 굴절률이 아니라 **"빛이 진행하는 얇은 막 자체의 굴절률"**임을 명심하세요.
